# Установка и использование

Нужны Android Studio с поддержкой версии AGP из `gradle/libs.versions.toml`, Android SDK Platform 36, Platform Tools, JDK 25 для Gradle daemon (версия закреплена в проекте) и устройство Android 8.0 / API 26 или новее. Целевой API — 36. Java-совместимость исходников — 17. При первой сборке нужны доступ к репозиториям зависимостей и место для Gradle, APK и распакованных моделей.

Из корня хакатонного репозитория в PowerShell:

```powershell
Set-Location src/mobile/android
.\gradlew.bat :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

В Linux/macOS используйте `./gradlew`. В Android Studio откройте `src/mobile/android`, дождитесь синхронизации и запустите конфигурацию `app`. SDK укажите в Android Studio или через `ANDROID_HOME`. Gradle восстановит GigaAM из четырёх частей и проверит SHA-256. Python 3 нужен только для вспомогательных проверок.

1. Откройте настройки моделей транскрипции, установите из APK Whisper Tiny RU или GigaAM и выберите модель.
2. Разрешите доступ к микрофону, запишите реплику и остановите запись. Для существующего файла используйте импорт.
3. Запустите транскрипцию из карточки записи. Откройте результат в истории, проверьте текст, интервалы и воспроизведение. Для проверки автономности повторите сценарий в авиарежиме.
4. На чистой установке без ECAPA текст сохраняется с меткой `speaker_unknown`.

## Локальная оценка ECAPA

В локальной копии пара хранится в `src/mobile/android/local-models/ecapa/`. Для закрытого теста скопируйте оба файла в `app/src/debug/assets/models/diarization/` относительно Android-проекта и пересоберите debug APK. После теста уберите эти копии и удалите приватную сборку с устройства перед проверкой чистого сценария. Приложение проверяет обе контрольные суммы. Пара и содержащий её APK предназначены для локальной оценки.
