# Установка и использование

Нужны Android Studio с поддержкой версии AGP из `gradle/libs.versions.toml`, Android SDK Platform 36, Platform Tools, JDK 25 для Gradle daemon (версия закреплена в проекте) и устройство Android 8.0 / API 26 или новее. Целевой API — 36. Java-совместимость исходников — 17. При первой сборке нужны доступ к репозиториям зависимостей и место для Gradle, APK и распакованных моделей.

Из корня хакатонного репозитория в PowerShell:

```powershell
Set-Location src/mobile/android
.\gradlew.bat :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

В Linux/macOS используйте `./gradlew`. В Android Studio откройте `src/mobile/android`, дождитесь синхронизации и запустите конфигурацию `app`. SDK укажите в Android Studio или через `ANDROID_HOME`. Gradle восстановит GigaAM из четырёх частей и проверит SHA-256. Python 3 нужен только для вспомогательных проверок.

1. Откройте настройки моделей транскрипции, установите из APK Whisper Tiny RU или GigaAM и выберите модель.
2. Разрешите доступ к микрофону, запишите реплику и остановите запись. Для существующего файла используйте импорт.
3. Запустите транскрипцию из карточки записи. Откройте результат в истории, проверьте текст, интервалы и воспроизведение. Для проверки автономности повторите сценарий в авиарежиме.
4. На чистой установке без ECAPA текст сохраняется с меткой `speaker_unknown`.

## Локальная оценка ECAPA

В локальной копии пара хранится в `src/mobile/android/local-models/ecapa/`. Для закрытого теста скопируйте оба файла в `app/src/debug/assets/models/diarization/` относительно Android-проекта и пересоберите debug APK. После теста уберите эти копии и удалите приватную сборку с устройства перед проверкой чистого сценария. Приложение проверяет обе контрольные суммы. Пара и содержащий её APK предназначены для локальной оценки.

## Подготовка окружения

Версии библиотек и плагинов закреплены в `src/mobile/android/gradle/libs.versions.toml`. Используйте Gradle Wrapper из проекта. На проверенном компьютере сборка выполнялась на Windows с JDK 25 из Android Studio.

1. Установите Android Studio и через SDK Manager установите Android SDK Platform 36 и Platform Tools.
2. Откройте папку `src/mobile/android` как самостоятельный Gradle-проект.
3. Укажите JDK 25 для Gradle и путь к Android SDK. Для консольного запуска задайте переменные окружения.
4. Дождитесь загрузки зависимостей и синхронизации. Для последующих сборок можно использовать `--offline`, если все зависимости уже доступны.

Пример для стандартных путей Windows, из корня репозитория:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
Set-Location src/mobile/android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
& "$env:ANDROID_HOME\platform-tools\adb.exe" devices
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app/build/outputs/apk/debug/app-debug.apk
```

Для установки через ADB включите на телефоне режим разработчика и отладку по USB, подключите телефон и подтвердите доступ компьютера. Если подключено несколько устройств, используйте `adb -s <серийный-номер>`. Эмулятор пригоден для проверки интерфейса, но GigaAM в каталоге требует ARM64.

## Модели и место на устройстве

| Модель | Архив в APK | Требования каталога |
| --- | --- | --- |
| Whisper Tiny RU | 102 747 308 байт | ОЗУ от 4096 МиБ |
| GigaAM v3 E2E CTC INT8 | 155 314 569 байт | ОЗУ от 4096 МиБ, Android API 26+, ARM64 |

Это заявленные в коде условия доступности. Фактическое качество и устойчивость на каждом устройстве требуют проверки. Помимо APK нужны место для распакованных моделей, записи и временного WAV. Для моно PCM 16 кГц / 16 бит один час звука занимает примерно 115,2 МБ без учёта заголовка.

Архив GigaAM собирается автоматически из `model-parts/gigaam/`. Сохраните все четыре части и `manifest.json`. Установка моделей внутри приложения читает архивы из APK и сверяет SHA-256.

## Результат обработки

Текст сохраняется в JSON UTF-8. При использовании стандартного места сохранения код указывает каталог `Documents/FluffyDisco`. В настройках можно выбрать собственную папку для транскриптов. Доступ к ней выдаётся через системный выбор каталога.

Пример формата, данные условные:

```json
{
  "schemaVersion": 1,
  "source": "local",
  "segments": [
    {
      "startMs": 0,
      "endMs": 3000,
      "speakerId": "speaker_unknown",
      "text": "Пример распознанной реплики."
    }
  ]
}
```

Время хранится в миллисекундах. Метка спикера относится к группе голоса в записи. Проверяйте важные фрагменты текста по исходному аудио.

## Устранение проблем

| Симптом | Проверка и действие |
| --- | --- |
| Gradle не находит SDK или Java | Проверьте выбранный Gradle JDK, `JAVA_HOME`, `ANDROID_HOME` и SDK Manager |
| Первая сборка не работает с `--offline` | Выполните сборку с доступом к репозиториям зависимостей |
| Не восстанавливается GigaAM | Проверьте наличие четырёх частей, manifest и контрольные суммы. Повторно получите повреждённые файлы |
| Модель недоступна в настройках | Сверьте архитектуру процессора, Android и ОЗУ с требованиями каталога |
| Вместо спикеров `speaker_unknown` | Проверьте наличие и целостность обоих файлов ECAPA. Без них доступна транскрипция |
| Импорт не обрабатывается | Проверьте воспроизведение файла, поддержку его кодека Android и доступ к выбранному документу |
| JSON не сохраняется в выбранную папку | Повторно выберите доступный для записи каталог и проверьте свободное место |
| ADB показывает `unauthorized` | Разблокируйте телефон и подтвердите ключ отладки |
| Установка APK сообщает о несовместимой подписи | Используйте сборку с подходящей подписью. Перед переустановкой с удалением приложения сохраните нужные данные |

Подробный порядок проверок и результаты переноса находятся в [TEST_RESULTS.md](TEST_RESULTS.md).
