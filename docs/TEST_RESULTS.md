# Методика и результаты тестирования

## Воспроизводимые проверки

Из `src/mobile/android`:

```powershell
python -B -m unittest discover -s tests -v
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:compileDebugAndroidTestKotlin
python -B scripts/verify_model_apk.py app/build/outputs/apk/debug/app-debug.apk
adb devices
.\gradlew.bat :app:connectedDebugAndroidTest
```

Для прогона на устройстве зафиксируйте коммит, версию Android, модель телефона, тип сборки, выбранную ASR-модель и наличие ECAPA. Используйте свежую установку для проверки отсутствия ECAPA. Диагностику ECAPA запускайте отдельно на закрытой сборке с обоими файлами. Пропуски в отчёте указывайте отдельно от успешных тестов.

| Проверка | Вход и шаги | Критерий |
| --- | --- | --- |
| Автономность | Авиарежим, установка каждой ASR-модели, запись и импорт одной известной русской реплики | Текст и интервалы доступны в истории после перезапуска, аудио воспроизводится |
| Отсутствие ECAPA | Чистая установка без пары, известная речевая запись | Текст сохранён, `speaker_unknown` |
| Локальная ECAPA | Закрытая сборка, `EcapaDiagnosticInstrumentedTest`, референсное аудио | Проверяются граф и sidecar, инференс выдаёт конечные 192-мерные векторы |
| Ошибки и повтор | Повреждённый аудиофайл, затем корректный импорт | Ошибка видна, повтор с корректным файлом завершает обработку |
| Качество и ресурсы | Размеченные русские записи с одним и несколькими голосами, короткие и длинные записи | Записать WER = (S+D+I)/N, DER с оговорённым collar и учётом перекрытий, RTF = время обработки / длительность записи, пик PSS в МиБ |

Для измерения PSS снимайте серию `adb shell dumpsys meminfo com.example.fluffydisco` в ходе обработки. Для DER подготовьте эталонные интервалы и сопоставьте произвольные идентификаторы спикеров. Фиксируйте настройки, разметку, число повторов и отдельные ошибки в [журнале](../artifacts/test-results/results.csv). Используйте записи с разрешением участников.

## Подтверждённые результаты

Исторические проверки исходного проекта приведены в [отчёте о диаризации](../src/mobile/android/docs/diarization-report.md). В частности, на SM-G996N / Android 14 был успешный запуск проверки загрузки ECAPA и инференса. Он относится к прежней локальной сборке. Метрики WER, DER, RTF и пика PSS для перенесённой версии не измерены.

Перенос проверен 2026-11-08 на Windows. Результаты запуска инструментов и сборки записаны в CSV. Подключён телефон с установленным Fluffy Disco. Тесты на устройстве не запускались, чтобы сохранить установленную сборку и её данные.
