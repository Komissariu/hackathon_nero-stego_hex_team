# Акустический протокол

В текущем проекте микрофон принимает речь для записи и распознавания. Приложение не кодирует файлы в звук и не декодирует акустические пакеты. Физический уровень передачи, формат кадра, синхронизация, контроль целостности, подтверждения и повторы отсутствуют. Соответственно, сценарии передачи по расстоянию и проверки хеша принятого файла к этой версии неприменимы.

Проверяемый сценарий — запись или импорт, преобразование в PCM, локальная транскрипция, сохранение JSON и просмотр результата. [Методика проверки](TEST_RESULTS.md).
